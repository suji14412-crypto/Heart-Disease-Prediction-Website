About the project

Why predict heart disease?

Heart disease is one of the leading causes of death worldwide. Spotting risk patterns early can help doctors decide who needs further tests and care.

How can machine learning help?

A machine learning model looks at many health values at once (age, blood pressure, cholesterol and more) and learns which combinations are linked with heart disease in past records.

Project objectives

  • Clean and prepare a real-world clinical dataset.
  • Explore the data with charts and statistics.
  • Train a Logistic Regression classifier.
  • Evaluate it on data it has never seen.
  • Present the work in a simple website.
Logistic Regression in simple English: it gives each input a weight, adds them up, and turns the total into a probability between 0 and 1. If the probability is above 0.5, it predicts "disease"; otherwise "no disease".

Data preprocessing

Missing-value imputation (median and mode)

Real data often has empty cells. For number columns we fill gaps with the median (the middle value, which is not distorted by extreme values). For category columns we use the mode (the most common value).

Duplicate record checking

If the same patient row appears twice, the model may learn it too strongly. We check for repeated rows and handle them so every record counts fairly.

Label Encoding

Models work with numbers, not words. Label Encoding turns text categories (for example "Male" and "Female") into numbers (for example 1 and 0).

Data preparation before training

After cleaning and encoding, the data is split into input features (X) and the target (y), and then into training and testing sets so the model can be tested fairly.

Model information

Artificial Intelligence (AI) is the field of building computer systems that do tasks which normally need human intelligence, such as understanding language, recognising images or making decisions.

Machine Learning (ML) is a part of AI. Instead of writing every rule by hand, we give the computer data and let it learn the patterns by itself.

Supervised learning means learning from examples that already have the correct answer (a label). Here, every patient record is labelled 0 or 1, so the model can learn from them.

Classification is a supervised task where the answer is a category, not a number. Our categories are "disease" and "no disease".

Logistic Regression is a classification algorithm. It combines the inputs into one score and passes it through the sigmoid function, which squeezes any number into a probability from 0 to 1.

With only two possible outcomes, Logistic Regression is a natural fit. It outputs a probability, it is fast to train, and its weights are easy to read and explain, which matters in healthcare.

Project summary

What it does

It cleans a 920-record clinical dataset and trains Logistic Regression to classify records as disease or no disease.

What I learned

How an ML project flows from raw data to evaluation, and how to read accuracy, precision and recall.

Role of Logistic Regression

It is the core classifier. It turns the patient's values into a probability and then into a 0 or 1 decision.

Why preprocessing matters

Missing values, duplicates and text categories can confuse a model. Clean, numeric data gives more reliable learning.

Limitations

One dataset, one simple model and no clinical validation. The website demo does not use the real model.

Future improvements

Save the trained model, serve it with Flask or FastAPI, connect it to this form, and compare other algorithms.
